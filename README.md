# EssentiallyAString

`EssentiallyAString` is a protocol which helps you make types which are essentially strings. This greatly improves the ergonomics of any type which should essentially be used like a string, letting you use them in most of the ways a `String` can be used.

This package powers [the `SpecialString` package](https://github.com/RougeWare/Swift-Special-String)!
